# Contributing to meeting-transcriber-action-extractor

Thank you for contributing to **meeting-transcriber-action-extractor** by [Vecesta.co](https://github.com/Vecesta-co)!

## Development Setup
```bash
git clone https://github.com/Vecesta-co/meeting-transcriber-action-extractor.git
cd meeting-transcriber-action-extractor
pip install -e ".[dev]"
pytest --cov=src
```

## Pull Request Guidelines
- Follow conventional commits (`feat:`, `fix:`, `docs:`, `test:`).
- Verify all unit tests pass with `pytest`.
